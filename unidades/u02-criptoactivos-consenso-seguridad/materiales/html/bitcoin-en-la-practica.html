Concepto base

¿Qué es Bitcoin y cómo se usa?

Bitcoin es una red de dinero digital descentralizada; la wallet es la interfaz con la que una persona envía, recibe y administra el acceso a sus fondos.

B

Blockchain Bitcoin

Red descentralizada que registra transacciones.

R

Registros

Las operaciones quedan asentadas de forma pública e inalterable.

K

Clave privada

Permite autorizar el gasto y debe mantenerse secreta.

W

Wallet

Interfaz para enviar, recibir y administrar Bitcoin.

D

Dispositivo

Celular, PC o hardware wallet desde donde operás.

Ejemplo práctico: si cambiás de teléfono pero conservás tu seed phrase, podés recuperar el acceso a tus fondos desde otra wallet compatible.

Dos formas de pago

On-chain vs Lightning Network

Ambas usan Bitcoin, pero responden a necesidades distintas: liquidación final y pagos cotidianos rápidos.

On-chain

La transacción se transmite a la red Bitcoin y queda registrada directamente en la blockchain.

Wallet→Red Bitcoin→Blockchain→Comerciante
VelocidadMinutos o más.
CostoVariable según congestión.
Uso típicoMontos grandes y liquidación final.
ConfirmaciónRequiere confirmaciones de red.

Lightning

Red de pagos de segunda capa sobre Bitcoin, pensada para pagos instantáneos o casi instantáneos.

Wallet→Lightning→Comerciante
VelocidadSegundos o milisegundos.
CostoMuy bajo.
Uso típicoCafé, tiendas y micropagos.
ConfirmaciónPrácticamente inmediata.
En la vida cotidiana, Lightning suele ser la opción más práctica para compras pequeñas.

Nueva sección

Tipos de wallets taxonomía práctica

No existe una única clase de wallet: se clasifican según custodia, conexión, dispositivo y función técnica.

1. Según quién controla las claves

  • Custodial: un tercero guarda las claves.
  • Non-custodial: vos controlás clave y seed phrase.

2. Según conexión a internet

  • Hot wallet: conectada o usada online.
  • Cold wallet: aislada u offline para ahorro.

3. Según dispositivo

  • Mobile wallet, desktop wallet y web wallet.
  • Hardware wallet para firmar con mayor seguridad.

4. Según función técnica

  • On-chain wallet y Lightning wallet.
  • Watch-only y multisig para monitoreo o seguridad avanzada.
Idea clave: las categorías se superponen. Una wallet móvil puede ser hot + software + non-custodial + Lightning.

Lectura correcta

Cómo se combinan las categorías de wallets

Una wallet real suele mezclar varias características. La pregunta no es solo qué app uso, sino qué riesgos y controles tengo.

Wallet móvil autocustodiada

mobile + hot + non-custodial + on-chain / Lightning

Uso cotidiano con control de claves.

Wallet de exchange

web/app + hot + custodial

Cómoda para comprar/vender, depende de un tercero.

Hardware wallet

hardware + cold + non-custodial

Ahorro y montos relevantes a largo plazo.

Watch-only

solo lectura + monitoreo

Permite ver saldos sin poder gastar.

Multisig

varias firmas necesarias

Mayor seguridad institucional o patrimonial.

Checklist: ¿quién controla las claves? ¿online u offline? ¿para gastar o ahorrar? ¿necesito Lightning? ¿qué nivel de seguridad necesito?

Control y custodia

PC, Exchange y Hardware Wallet

Tres formas de interactuar con Bitcoin, con diferentes niveles de control sobre las claves.

Wallet de escritorio

Permite enviar y recibir desde la PC. Puede conectarse a un nodo propio.

Autocustodia: vos controlás las claves en la computadora.

Exchange

Forma simple de comprar, vender o convertir BTC a moneda local.

Custodia de terceros: la plataforma suele guardar las claves.

Hardware wallet

Firma transacciones mientras protege las claves privadas fuera de la computadora.

Autocustodia fría: ideal para ahorro y montos relevantes.

Not your keys, not your coins

Resume que si no controlás las claves privadas, dependés de un tercero para acceder a esos bitcoins.

Pagos en el mundo real

Otras formas de pago y uso

Bitcoin también puede integrarse a tarjetas, NFC, cajeros, terminales comerciales y nodos propios.

Tarjeta vinculada a cripto

Pagás como con una tarjeta tradicional; el proveedor puede convertir BTC a moneda fiat.

NFC / Lightning

Micropagos rápidos acercando teléfono o tarjeta compatible.

Smartwatch

Interfaz ligera para pagos pequeños.

Cajero Bitcoin

Conecta efectivo con BTC mediante QR de una wallet.

Terminal POS

El comercio genera QR o cobra mediante procesador de pagos.

Nodo Bitcoin

Valida la red y permite mayor privacidad, soberanía y control técnico.

Importante: a veces el comercio no recibe BTC directamente; un intermediario puede convertir los fondos a pesos, dólares u otra moneda.

Seguridad

Custodia, seed phrase y seguridad

Proteger el acceso a tus criptoactivos es clave: quien controla la clave privada controla los fondos.

₿

Fondos en blockchain

Asociados a direcciones, no a la wallet en sí.

K

Clave privada

Autoriza transacciones y permite mover fondos.

W

Wallet

Interfaz para gestionar claves y firmar operaciones.

S

Seed phrase

Lista de 12 o 24 palabras que permite recuperar la wallet.

Buenas prácticas

  • Guardar la seed phrase offline.
  • No compartirla.
  • Verificar direcciones.
  • Usar hardware wallet para montos relevantes.
Importante: quien obtiene la seed phrase de una wallet autocustodiada puede reconstruir las claves y tomar control de los fondos.
