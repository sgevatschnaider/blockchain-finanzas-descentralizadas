# Planillas de laboratorio

`laboratorio-bitcoin.xlsx` contiene tres hojas:

1. **Experimentos PoW:** registra intentos y tiempos observados, calcula intentos y tiempos esperados.
2. **Riesgo de reversión:** compara una aproximación didáctica de alcance para distintas proporciones de hashrate atacante y confirmaciones.
3. **Ruta de laboratorios:** permite registrar estado y observaciones de las nueve simulaciones.

El archivo XLSX se puede subir o abrir directamente en Google Sheets. `registro-experimentos-pow.csv` ofrece una alternativa liviana para importar únicamente los datos de minería.
