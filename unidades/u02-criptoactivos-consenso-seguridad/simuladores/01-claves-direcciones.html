Precisión técnica: en Bitcoin real la clave pública se obtiene como P = d·G, una multiplicación escalar sobre la curva secp256k1. Qué representa una dirección según el tipo de salida

Clave pública ≠ dirección
P2PKHBase58Check · codifica HASH160 de una clave pública
P2SHBase58Check · codifica un hash de script
SegWitBech32 · codifica un witness program
TaprootBech32m · witness v1 con una output key tweakeada de 32 bytes

Idea clave

Una dirección Bitcoin es una representación codificada de los datos necesarios para crear una condición de gasto. Según el tipo de salida puede representar un hash de clave pública, un hash de script, un witness program o una clave pública de salida tweakeada. Por eso clave privada, clave pública y dirección son conceptos relacionados, pero distintos.
