    Abrir en Google / iniciar sesión
    Cómo compartir una presentación con toda la clase

    Para un visor público, en Google Slides elegí Archivo → Compartir → Publicar en la Web y pegá el enlace resultante. Si mantenés acceso restringido, cada alumno debe tener permiso y puede necesitar iniciar sesión en Google.

    Este visor no solicita contraseñas, no modifica permisos y no puede resolver bloqueos de autenticación de Google dentro del marco. Ante un aviso de acceso, usá el botón para abrir la presentación directamente en Google.
