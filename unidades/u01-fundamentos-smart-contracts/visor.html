    Permisos y presentación para toda la clase

    Para un visor público, en Google Slides elegí Archivo → Compartir → Publicar en la Web, publicá la presentación y pegá el enlace resultante. Publicar hace visible el contenido: elegí esta opción solo para material que quieras compartir públicamente. Si mantenés acceso restringido, cada alumno debe tener permiso y puede necesitar iniciar sesión en Google en otra pestaña.
