Ejecutá bytecode como una máquina virtual

Seguimiento paso a paso de program counter, stack, memory, storage y gas. Editá un programa simplificado, compilalo a bytecode didáctico y observá exactamente cómo cambia el estado interno de la EVM con cada opcode.

Objetivo de aprendizajeComprender la EVM como una máquina de pila determinista: cada instrucción consume operandos, produce resultados, puede modificar memoria/storage y avanza el program counter.

Memory

volátil durante la llamada
Memory: espacio byte-addressed y expansible usado durante la ejecución. Se reinicia entre llamadas. Este laboratorio muestra palabras de 32 bytes en offsets utilizados.

Storage

estado persistente del contrato
Storage: slots de 32 bytes asociados al contrato. Es mucho más costoso que usar stack o memory; el costo exacto depende del acceso y de la transición del valor.
