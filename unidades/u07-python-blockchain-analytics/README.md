# U7 — Python y Blockchain Analytics

Unidad de cierre orientada a transformar datos on-chain en evidencia reproducible. La ruta conecta consulta de fuentes, limpieza, métricas, visualización y comunicación de resultados.

## Objetivos

- Consultar y normalizar datos de blockchain y mercados.
- Diseñar análisis reproducibles con Python, pruebas y dependencias declaradas.
- Interpretar eventos ERC-20 y series temporales sin confundir correlación con causalidad.
- Comunicar supuestos, límites y riesgos de calidad del dato.

## Proyecto integrador sugerido

Construir un pipeline pequeño que ingiera una fuente pública, documente su esquema, calcule una métrica on-chain, valide casos límite y produzca una visualización acompañada por una interpretación crítica.
